# SGA - Sistema de Gestão de Ativos via QR Code

### 🎓 Projeto Integrador - UNIVESP (Engenharia de Computação)

O **SGA** é uma solução para otimizar o inventário e manutenção de ativos usando **QR Code**, facilitando o dia a dia técnico com registros rápidos e precisos.

## 🛠️ Tecnologias
- **Back-end:** Python / Flask
- **Front-end:** HTML5 / CSS3
- **Banco de Dados:** SQLite
- **Design:** Figma

## ⚙️ Como executar
1. Ative o venv: `.\venv\Scripts\Activate.ps1`
2. Instale o Flask: `pip install flask`
3. Rode: `python app.py`
